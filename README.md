# Лендинг: Auto Shop Ad Leak Teardown

## Что это

Одна страница на английском под переход с YouTube. Логика прогрева:

1. **Первый экран** — «реклама работает, деньги всё равно утекают». Не обещание, а потеря.
2. **Калькулятор справа** — человек вбивает свой бюджет, цену клика и сколько звонков
   пропускает за неделю. Видит сумму потерь в месяц. Считается прямо в браузере,
   никуда не уходит, пока он сам не оставит заявку.
3. **Шесть утечек** — раскрывающиеся карточки, в каждой «как проверить самому сегодня».
   Это то, что делает страницу полезной, а не рекламной: он уходит с действиями,
   даже если не оставил заявку.
4. **Кейсы** — три карточки, цифры до/после.
5. **Оффер** — бесплатный разбор аккаунта с записью экрана, форма.
6. **FAQ** — снимает возражения «почему бесплатно», «отдавать ли доступ», «у меня агентство».

Светлая тема, адаптив, никаких внешних библиотек и шрифтов — грузится мгновенно,
что для этой темы принципиально: странно рассказывать про медленные сайты на медленном сайте.

## Что надо подставить перед запуском

В `index.html`, внизу в блоке `CONFIG`:

```js
const CONFIG = {
  endpoint: "https://autoshop-leads.ТВОЙ-САБДОМЕН.workers.dev",
  whatsapp: "375291234567"   // только цифры
};
```

Всё, что я не мог знать, помечено в коде пунктирной красной рамкой — атрибут `data-ph`.
Найти можно поиском по `data-ph`. Это:

- три цифры в первом экране (сколько аккаунтов разобрано, сколько слитого нашёл, на сколько
  срезал стоимость заказа);
- три кейса целиком — тип сервиса, цифры до/после, что было сломано, что поменяли, за какой срок;
- домен в подвале;
- название бренда в шапке (сейчас MAX.MARKETING).

**Я их не придумывал специально.** Кейсы с выдуманными цифрами — это то, за что в США
прилетает от FTC, и это первое, что проверяет вменяемый владелец сервиса. Дай реальные,
подставлю за пять минут. Если реальных кейсов именно по авторемонту в США пока нет —
скажи, переделаю блок под «как проходит разбор», там цифры не нужны.

## Заявки в Telegram

Делается одной командой. npm и wrangler не нужны — скрипт ходит в Cloudflare через curl.

Один раз, минут на пять:

1. Завести бесплатный аккаунт на `dash.cloudflare.com`
2. Скопировать **Account ID** — он справа на главной странице дашборда
3. My Profile → API Tokens → Create Token → шаблон **Edit Cloudflare Workers**

Потом:

```bash
export CF_ACCOUNT_ID=сюда_account_id
export CF_API_TOKEN=сюда_токен
bash "/Users/maksim/Desktop/ютуб/us-youtube/landing/deploy-bot.sh" https://твойдомен.com
```

Скрипт сам: зальёт воркер, положит токен бота в секреты Cloudflare, включит адрес,
впишет его в `index.html` и отправит тестовую заявку — ты сразу увидишь её в телеге.

Бот берётся тот же, что шлёт отчёты, из `~/.claude/bin/tg.env`. Если хочешь отдельного —
заведи у @BotFather и подмени значения в этом файле перед запуском.

В Telegram прилетит: имя, телефон, сервис, сайт, бюджет, что болит, что человек насчитал
в калькуляторе, источник и код видео. Снизу две кнопки — **написать в WhatsApp**
и **позвонить**, номер подставляется из заявки.

### Если воркера ещё нет

Страница не ломается. Форма отправится, не достучится до бэкенда и откроет WhatsApp
с уже набранным текстом заявки на твой номер — человеку остаётся нажать «отправить».
Для этого в `CONFIG.whatsapp` должен стоять твой номер, только цифры.

## UTM из YouTube

Ссылку в описании под каждым роликом давай с меткой, чтобы видеть, какое видео приносит
заявки:

```
https://твойдомен.com/?utm_source=youtube&v=01-missed-calls
```

`v` — любой короткий код ролика. Он придёт в заявку.

## Хостинг

Статика, никакой сборки. Любой вариант:

- GitHub Pages — положить `index.html` в репозиторий, включить Pages;
- Cloudflare Pages — удобнее, потому что воркер уже там же;
- Netlify — перетащить папку.

Домен прикручивается в настройках хостинга.

## Проверить перед запуском

- [ ] Открыть с телефона на мобильном интернете, не с вайфая
- [ ] Отправить тестовую заявку, убедиться, что дошла в Telegram
- [ ] Подставить свой номер в `CONFIG.whatsapp` — на нём держится запасной путь
- [ ] Нажать кнопку WhatsApp в этом сообщении — должна открыться переписка
- [ ] Прогнать через PageSpeed Insights, вкладка Mobile
- [ ] Перечитать кейсы: каждая цифра должна быть такой, которую ты готов показать клиенту
